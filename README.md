# Toggleable Hitbox (Minecraft 1.21.11, Fabric)

A tiny client-side Fabric mod that toggles entity hitboxes with a single key.

- **Default key:** `H` (rebind under *Options → Controls → Key Binds → Toggleable Hitbox*)
- Shows `Hitboxes: ON` / `Hitboxes: OFF` above the hotbar.
- Uses the same setting as vanilla `F3 + B`, so the two stay in sync.

## Install
1. Install [Fabric Loader](https://fabricmc.net/use/) for 1.21.11 and [Fabric API](https://modrinth.com/mod/fabric-api).
2. Build with `./gradlew build` (Java 21+), or download the jar from the GitHub Actions "Artifacts".
3. Put `build/libs/toggleable-hitbox-1.0.0.jar` in your `.minecraft/mods` folder.
