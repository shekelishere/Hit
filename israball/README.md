# Israball

Storefront preview for Israball: youth football boots, shin guards and balls for shoppers in Israel. Hebrew first, with English.

- Single static page: `index.html` (inline CSS and JS, Google Fonts only). Open it in a browser or serve the folder.
- Size finder: enter the foot length in cm, get the EU size and the inner boot length to look for, then filter the boots to that size.
- Hebrew/English toggle switches text direction. ₪/$ toggle ($ is an estimate at 3.7).
- Cart persists in the browser's localStorage. Checkout is not connected: payments are out of scope until launch.
- Responsive: a bottom cart bar on phones; follows the system light/dark theme.

Product names, prices and measurements are sample content for the preview. Research behind the direction is in `../.copycat/RESULT.md`.
